# Web / PWA client

Responsive web client for iPhone, iPad, desktop and other modern browsers.

The web application will use the same API and permission model as Android and will be designed as an installable PWA where platform support permits.

Initial screens:

- Sign in / registration
- My files
- Folder view
- Upload manager
- Shared with me
- Share dialog / link management
- Trash
- Profile and storage usage

The client must not expose storage credentials or bypass backend authorization.
